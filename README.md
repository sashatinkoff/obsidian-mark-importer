# MarkImporter для Obsidian

Плагин создаёт заметку из любого источника с сохранением вёрстки и показывает предпросмотр «оригинал | результат» перед созданием.

## Установка

1. Распакуйте архив. Папку `mark-importer` целиком скопируйте в `<хранилище>/.obsidian/plugins/`.
2. Перезапустите Obsidian или нажмите «Перезагрузить плагины», затем включите **MarkImporter** в разделе «Сторонние плагины».
3. Окно открывается тремя способами: иконкой ⚡ на боковой панели, командой «MarkImporter: Открыть окно импорта» или через контекстное меню на PDF/DOCX в хранилище.

Сборка не нужна. `main.js` сам подгружает модули из `src/`.

## Источники

| Источник | Что сохраняется |
| --- | --- |
| **PDF** (файл, ссылка, файл из хранилища) | колонки в правильном порядке чтения, заголовки по кеглю, абзацы со склейкой переносов, списки, таблицы, иллюстрации, подписи «Рис./Таблица», ссылки, надстрочные индексы, центрирование. Колонтитулы и номера страниц убираются. По желанию можно добавить картинку каждой страницы 1:1 |
| **Сайты** | основной контент без меню, рекламы и комментариев (Хабр, ЖЖ, Medium, Substack, Wikipedia, GitHub, Telegraph…), ленивые картинки, формулы KaTeX/MathJax/MathML → `$…$`, код с языком, вложенные списки, чек-листы, таблицы, врезки → callouts, `<details>` → сворачиваемый callout, YouTube → встраивание. Кодировка windows-1251 определяется автоматически |
| **Telegram** | `t.me/канал/123` превращается в пост, `t.me/канал` или `@канал` в ленту из N постов (одной заметкой или заметкой на каждый пост). В заметку попадают форматирование, фото и альбомы, видео, опросы, превью ссылок, пересылки, ответы и просмотры |
| **Буфер обмена** | HTML из браузера, Telegram Desktop, Word и Google Docs (жирный и курсив из inline-стилей), а также Markdown, простой текст и картинки. Если в буфере лежит ссылка, загружается страница |
| **DOCX / HTML / TXT / MD** | стили заголовков, списки с вложенностью, таблицы с объединёнными ячейками, цвет, выделение, картинки с шириной, цитаты и код по стилям |

## Окно плагина

- **Источники и импорт**: файл, ссылка, Telegram или буфер плюс параметры разбора.
- **Конструктор и предпросмотр**:
  - три режима: *Без вёрстки*, *С вёрсткой оригинала*, *Конструктор блоков*. В конструкторе блоки можно перетаскивать, отключать и фильтровать по типам;
  - виды: *Оригинал / Рядом / Результат*. Для PDF оригинал показывается сканом страниц с масштабом;
  - правка исходника (Raw), копирование Markdown, выбор папки с автоподстановкой, переименование заметки;
  - **Ctrl/Cmd + Enter** создаёт заметку.
- **Статистика и журнал**: счётчики, график по дням, распределение блоков, теги, журнал с поиском, фильтрами и экспортом (CSV или заметка).

## Закладка для браузера

В настройках есть кнопка «Скопировать». Скопированный код вставьте как адрес закладки в браузере. Нажатие на эту закладку отправит текущую страницу в MarkImporter через `obsidian://markimporter?url=…`.

## Структура

```
mark-importer/
├── main.js              загрузчик модулей src/* + класс плагина
├── manifest.json
├── styles.css           тема Emerald (тёмная и светлая)
└── src/
    ├── plugin.js        команды, меню файлов, протокол, вид
    ├── settings.js      вкладка настроек + автоподстановка папок
    ├── constants.js · util.js
    ├── session.js       сессия импорта: блоки, режимы, сборка Markdown
    ├── assets.js        вложения: предпросмотр → файлы в хранилище
    ├── save.js          создание заметок
    ├── store.js         журнал и агрегаты статистики
    ├── convert/         html2md · readability · pdf · docx · zip · text
    ├── sources/         web · telegram · clipboard · file · pdf · common
    └── ui/              view · sourcesTab · builderTab · statsTab · dom
```

## Ограничения

- Работают только публичные каналы Telegram, у которых включён веб-просмотр `t.me/s/…`. Закрытые чаты можно скопировать из Telegram Desktop и вставить через «Буфер обмена».
- Сканы PDF без текстового слоя (OCR) не распознаются: текст из них не извлекается. Для таких файлов включите «Страницы картинками».
- Форматы `.doc`, `.rtf`, `.odt` не поддерживаются. Сохраните документ как DOCX.
